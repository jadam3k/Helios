# Credits

Helios is my greenhouse watering project. I used AI assistance for firmware development, debugging and documentation. The recorded build results describe software checks; hardware validation is still needed.

- STMicroelectronics: STM32 devices, STM32CubeIDE and the STM32 HAL/CMSIS files supplied with DRIVER2. Their license files remain in `Boards/DRIVER2/Filmware/Drivers/`.
- STM32duino / STMicroelectronics: the Arduino STM32 core used to build MPPT. It is installed separately through Boards Manager.
- KiCad and the footprint/symbol libraries used by the board projects.
- Component manufacturers and suppliers: datasheets, footprints and 3D models stored with the projects. Imported assets retain their original terms; they are not all original Helios designs.
